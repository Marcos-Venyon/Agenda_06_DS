# Calculadora de Descontos em Python

Este é um script simples e otimizado em Python que recebe o valor de uma compra e aplica um sistema de descontos progressivos.

## 🚀 Funcionalidades

O programa avalia o valor inserido pelo usuário e aplica a seguinte regra de negócio:
- **Valores negativos:** Retorna uma mensagem de alerta (valor inválido).
- **Abaixo de R$ 200,00:** Aplica 5% de desconto.
- **De R$ 200,00 a R$ 299,99:** Aplica 10% de desconto.
- **A partir de R$ 300,00:** Aplica 15% de desconto.
